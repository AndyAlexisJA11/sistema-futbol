
# Sistema de Gestion de futbol

Aplicacion web para digitalizar la administracion de torneos de futbol locales.

## Problema

La directiva lleva manualmente en papel los registros de equipos, jugadores,
resultados, goleadores, tarjetas, sanciones y tablas de posiciones.

## Objetivo

Centralizar la informacion del campeonato y automatizar los calculos deportivos,
facilitando la gestion de la directiva y la consulta de informacion por parte de la
aficion.

## Estado del proyecto

En etapa de analisis, documentacion y preparacion tecnica.
